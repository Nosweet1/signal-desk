# 信号台划词 · 浏览器插件

选中任意英文 → 单词给音标 + 中文释义，句子给整句翻译。不登录、不跟踪、无广告。

## 安装（Chrome / Edge，1 分钟）

1. 打开 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」
4. 选择整个 **`ext`** 文件夹（就是本文件所在的目录）
5. 装好后随便找个英文网页，用鼠标选中一个单词试试

> 换了新电脑或重装了浏览器，重复上面 5 步即可。目录别删，删了插件就失效。

## 用法

| 操作 | 效果 |
| --- | --- |
| 选中一个单词 | 音标 + 词性 + 中文释义 |
| 选中一句话 | 整句中文翻译，可复制 |
| 点 🔊 | 朗读原文 |
| 右键选区 → 信号台：翻译 | 手动触发（适合选中文字后气泡被挤掉的情况） |
| Esc / 点空白 | 关闭气泡 |

## 说明

- 单词优先查有道词典，查不到退英文释义站，再退机器翻译。
- 句子走 MyMemory 免费接口，每天约 5000 字符额度，够日常读新闻。
- 查询结果本地缓存 30 天，重复查同一个词不耗流量。
- 只处理英文内容，中文段落不触发，避免干扰正常阅读。
